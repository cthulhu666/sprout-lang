# Dead-code cleanup — 2026-06-08

Audit-driven removal of unreferenced functions across `stdlib/compiler/`.
Methodology and per-cluster details in commit messages.

Per AGENTS.md Code-and-Testing #3 (coverage gap on edited files): for several
clusters in this cleanup, no new test was added because the surviving code in
the touched file is already comprehensively exercised by existing tests. Each
cluster commit documents which existing test suite covers the surviving code.

## Cluster 1 — `stdlib/compiler/codegen.sprout` Emitter `next_*` / `bump_*` family

Removed 8 unused helpers: `es_next_tmp`, `es_next_blk`, `es_next_str`,
`es_next_lam`, `es_bump_tmp`, `es_bump_blk`, `es_bump_str`, `es_bump_lam`.

Superseded by direct `_ref` access (e.g. `ref_read(es_next_tmp_ref(em))`,
`ref_write(es_next_tmp_ref(em), n + 1)`) used everywhere in surrounding code.

No new coverage-gap test added: the surviving Emitter machinery
(`es_*_ref` field accessors + `es_add_line`, `es_set_cur_blk`, `es_add_def`,
`es_add_str_glb`, `es_set_fn_wrap` mutation helpers) is exercised by every
codegen test via the `stdlib.compiler.ir_lowering` pipeline (see
`tests/stdlib/test_ir_codegen_*.spr`) and end-to-end by the `just test`
driver verification step.

## Cluster 2 — `stdlib/compiler/codegen.sprout` IR assembly wrappers

Removed 2 unused helpers: `assemble_ir`, `join_lines`.

`assemble_ir` was a one-liner wrapper around `assemble_ir_sections` +
`join_line_sections`; callers invoke those directly. `join_lines` was a
one-liner wrapper around `string_join_newlines`; callers invoke that
directly.

No new coverage-gap test added: IR assembly is end-to-end exercised by
every codegen test (which renders complete IR programs) and by the
`just test` driver verification step.

## Cluster 3 — `stdlib/compiler/codegen.sprout` pre-type-aware param-rooting helpers

Removed 4 functions (the heuristic flagged 2 directly; reading the bodies
revealed 2 additional recursive-orphans whose only callers were the
heuristic-flagged ones):

  - `build_param_locals`         (heuristic flagged — no external caller)
  - `build_param_locals_acc`     (recursive-orphan; only caller was `build_param_locals`)
  - `push_roots_for_params`      (heuristic flagged — no external caller)
  - `push_roots_for_pairs`       (recursive-orphan; only caller was `push_roots_for_params`)

Superseded by `build_param_locals_and_push_roots` +
`build_param_locals_and_push_roots_acc`, which use the type-aware
GC rooting pass (skipping rooting for known scalars Int/Bool/Char per
the `ast.Param` annotation).

No new coverage-gap test added: the surviving fused-rooting path is
exercised by every codegen test that compiles a function with
parameters (effectively all of `tests/stdlib/test_ir_codegen_*.spr`)
and by `tests/stdlib/test_ir_rooting.spr` specifically.
